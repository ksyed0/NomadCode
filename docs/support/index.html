03 · FAQ

Frequently asked questions

Answers to the most common questions about NomadCode.

NomadCode is offline-first — your code lives on your device. Cloud sync is not available in v1.0. To share code across devices, use git: clone your repository on each device and push/pull via the built-in Git panel. Multi-device sync is planned for a future release.
AI completions require a Pro+AI subscription or a configured BYOK key (Pro plan). Check Settings → AI to verify your plan and configuration. If you have Pro+AI, make sure you have not hit your daily quota (15¢ on paid models — free models are unlimited). Free models reset daily at midnight UTC.

If completions still don't appear: ensure you have an internet connection and try switching to a different model in Settings → AI → Model.
Yes. The free tier includes the full code editor, file manager, terminal, and git integration with up to 3 open files. AI features and unlimited file access require a Pro or Pro+AI subscription. Subscriptions are managed through the App Store (iOS) or Google Play (Android) and can be cancelled at any time.
First, sign in with GitHub via Settings → Account → Sign in with GitHub. Once authenticated, open the Git panel (the branch icon in the left sidebar), tap Clone, and enter your repository URL. Private repositories are automatically authenticated using your stored OAuth token. NomadCode does not support SSH key-based authentication in v1.0 — HTTPS only.
NomadCode uses OpenRouter to provide access to 200+ models, including Claude (Anthropic), Gemini (Google), Llama (Meta), Mistral, and many others. You can search and select any model in Settings → AI → Model.

Free models (marked with a FREE badge) have no daily cost and no quota. Paid models are subject to the 15¢/day shared quota on the Pro+AI plan.

If you have your own API keys (Pro plan), you can configure BYOK with OpenRouter, Anthropic, Google, OpenAI, or any OpenAI-compatible endpoint.
iOS: Open the App Store → tap your profile photo → Subscriptions → NomadCode → Cancel Subscription.

Android: Open Google Play → tap your profile photo → Payments & subscriptions → Subscriptions → NomadCode → Cancel subscription.

Cancellation takes effect at the end of your current billing period. You retain access to your paid tier until that date. We do not offer refunds for unused portions of a billing period.
NomadCode's terminal runs a WASM-sandboxed shell — it does not have access to system binaries on your device. It supports a curated set of POSIX-style commands (ls, cd, cat, mkdir, rm, touch, git, node, npm, npx, and others). Commands that require native binaries (e.g. brew, apt, python installed outside the sandbox) will not work. This is a platform requirement for App Store / Google Play compliance. A more capable terminal runtime is planned for a future release.
Your code files are stored in the application sandbox on your device (iOS Documents directory / Android equivalent). They are not automatically backed up to FableSoft servers — there are none. On iOS, your files are included in iCloud Backup if you have iCloud Backup enabled for NomadCode. We strongly recommend using git to push your code to GitHub or another remote as your primary backup strategy. See our Privacy Policy for full data details.
